# Pavo AI Tools

A small collection of AI video tools I use, one section per product. Each entry links to the live site.

## Wan 3.0

**[Wan 3.0](https://wan-3.io)** — the Wan 3.0 video generation workspace: text-to-video, image-to-video, and motion control in the browser.

- Site: <https://wan-3.io>
- Good for: fast 5-10s clips with locked camera motion.

## Pavo AI

**[Pavo AI](https://pavoai.app)** — an all-in-one AI video platform covering generation, timeline editing, captions, and multilingual dubbing.

- Site: <https://pavoai.app>
- Prompt gallery: <https://pavoai.app/prompts>
- Good for: the full loop from storyboard to dubbed export without leaving the browser.

## Rea Video

**[Rea Video](https://reavideo.pro)** — video recreation and reference-driven generation: feed a reference clip, get a re-shot version.

- Site: <https://reavideo.pro>
- Good for: re-creating a shot you already like with a new subject.

## How I pick

| Need | Tool |
| --- | --- |
| Quick text-to-video with motion presets | [Wan 3.0](https://wan-3.io) |
| Storyboard → generate → edit → dub in one place | [Pavo AI](https://pavoai.app) |
| Re-shoot an existing reference clip | [Rea Video](https://reavideo.pro) |
